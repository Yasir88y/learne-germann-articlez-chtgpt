Sync progress between your devices

Your German noun learning history can be stored privately in a Supabase database and loaded on your phone, laptop, or other browser when you sign in with the same email address.

Why not store it in the GitHub directory? GitHub Pages serves static files; it cannot safely write each learner's records back into a public repository. This cloud database keeps private learning data separate from the public website source code.

One-time setup

1. Create a Supabase project

Visit Supabase Dashboard. Create a project on the free plan. You can also connect the Supabase plugin in ChatGPT so the project and database setup can be handled together.

2. Create the secure progress table

In the project's SQL Editor, run the contents of supabase-setup.sql. It enables row-level security so each signed-in user can only read and update their own records.

3. Configure email sign-in

In Supabase Authentication, enable Email sign-in and set the Site URL and Redirect URL to:

https://yasir88y.github.io/learne-germann-articlez-chtgpt/

The app sends a private sign-in link to your email. You won't need to remember another password.

4. Add your public configuration

Open cloud-config.js in GitHub. Replace the empty strings with your Supabase Project URL and publishable key (or older public anon key):

window.ARTIKEL_CLOUD_CONFIG = {
  url: "https://YOUR-PROJECT.supabase.co",
  publishableKey: "sb_publishable_..."
};

The publishable key is intended for browser apps. NEVER put a secret/service_role key, database password, or personal login token in GitHub files.

5. Sign in from your devices

Return to Artikel Studio, enter your email, and open the link in your inbox. Your existing local history is merged into the private cloud copy. On another device, sign in with that same email to load your saved words, correct and wrong answers, and spaced mastery progress.

Keep your backup

Before connecting a new device, use Backup / recover progress to download a JSON copy. Your local records continue to work if you are offline or cloud sync fails. Avoid practising simultaneously on two devices until they have both completed their first sync.

Cloud sync is optional. Until you configure it and sign in, your app remains a free local-only German article trainer and no browser data is transmitted to Supabase.
